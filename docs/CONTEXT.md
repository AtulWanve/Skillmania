# Docs

## Inputs
- Harness documentation, skill format specs, real-world examples of effective vs ineffective skills.

## Process
- Authoring guides: how to write a skill from scratch for each harness format.
- Decision framework: when to create a skill vs use a harness built-in vs write a one-off prompt.
- Format reference: the anatomy of a skill file (frontmatter, triggers, body, references).
- Milestone specifications: defining and tracking project phase boundaries in `docs/milestones/`.

## Outputs
- Guides and references that developers and collaborators can read to make informed skill decisions without AI assistance.
- Checked-in milestone phase records in `docs/milestones/M<N>-<name>.md`.
