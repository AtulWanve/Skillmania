# Standards

## Inputs
- Language and framework specifications for TypeScript, React, and Next.js
- Security compliance benchmarks and performance guidelines
- Engineering best practices and codebase naming conventions

## Process
- Establishes non-negotiable coding rules, architectural patterns, and quality gates
- Decouples rule definitions from review execution logic
- Governs formatting, type safety constraints, naming criteria, and documentation standards

## Outputs
- Static evaluation rules referenced by validation and review runners
- Quality thresholds and pass/fail criteria for code modifications
- Architectural and security constraints governing execution workflows
