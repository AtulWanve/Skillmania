# System

## Inputs
- Incoming task specifications and developer prompts
- High-level system requirements and architectural constraints
- Execution status signals from runtime orchestrators

## Process
- Defines high-level execution lifecycles, phase sequences, and orchestration boundaries
- Decomposes complex tasks into deterministic, step-by-step execution plans
- Enforces strict separation between workflow policies and concrete runtime implementations

## Outputs
- Validated execution plans and task decomposition trees
- Stage transition definitions and lifecycle specifications
- Policy contracts governing runtime dispatch
