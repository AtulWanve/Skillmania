# Templates

- Structural requirements for system records, tasks, memory docs, and reviews
- Schema updates for project documentation and reporting standards

## Process
- Defines boilerplate schemas, frontmatter fields, and section hierarchies

## Outputs

- Structural blueprints for runtime artifact generators
