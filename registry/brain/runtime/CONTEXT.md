# Runtime

## Inputs
- Execution plans and task directives generated by the system layer
- Structural node and edge data from the graph module
- Modular architectural state and synchronization checkpoints from memory
- Transient context records from cache

## Process
- Orchestrates multi-phase prompt lifecycles including classification, context loading, and execution
- Performs static code validation, automated review scoring, and confidence gating
- Executes atomic, idempotent synchronization of knowledge files and dependency graphs

## Outputs
- Executed file modifications and validation diagnostics
- Automated review evaluations and confidence scores
- Incremental updates dispatched to graph, memory, and task log stores
