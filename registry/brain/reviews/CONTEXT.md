# Reviews

## Inputs
- Source code patches, git diffs, and execution stage artifacts
- Quality benchmarks and constraints defined in the standards module
- Structured review checklists for security, architecture, performance, and code quality

## Process
- Evaluates code changes systematically against specialized review rubrics
- Calculates multidimensional confidence scores and identifies regressions
- Decouples evaluation criteria checklists from execution runtime engines

## Outputs
- Structured review feedback containing findings, severity levels, and remediation notes
- Numerical scoring breakdowns across quality, security, and architectural alignment
- Approval signals and gating decisions for automated integration
